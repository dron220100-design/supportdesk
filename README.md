# SupportDesk	
Продукт по обработке и учёту обращений в техническую поддержку.	
## Что решает	
Структурирует обращения, помогает собирать статистику и контролировать работу операторов, в контексте скорости и качества работы с обращениями.		
## Структура репозитория	
- docs/ - требования, глоссарий, договорённости	
- diagrams/ - схемы процессов и данных
- ad/ - записи об архитектурных решениях
- api/ - спецификации API
- src/ - исходный код проекта
