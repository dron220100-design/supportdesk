# DoD and DoR

## Definition of Ready - задачу можно брать в спринт, если...
- Есть детальное описание задачи исходя него понятно, что делать и зачем.
- Приложен макет изменения состояния
- Указаны роли пользователей которых затрагивает изменение
- Есть оценка по времени выполнения
- Определены зависимости от других задач и систем
- Подробно описаны критерии задача: что происходит и в какой последовательности

## Definition of Done - задача закончена, если...
- Написан код и прошло ревью
- Тесты написаны и проходят
- Задача развернута на тестовом контуре и проверена
- Выполнена приемка по критериям. Все они выполнены
- Обновлена документация
- Нет  критических багов по функционалу
