# Описание отдного из сценариев по шагам 

## Сценарий
Оператор открывает карточку обращения

## Шаг первый
Оператор открывает карточку запроса 
Пример: 
GET /api/submissions/{id} HTTP/1.1
Host: example.com
Authorization: Bearer YOUR_API_KEY
Accept: application/json

## Шаг второй
При открытии карточки обращения есть несколько вариантов

- Карточка успешн открыта (200 ОК)
- Нет авторизоции (401 Unauthorized)
- Запрещен доступ (403 Forbidden)
- Сервер не ответил во время  (500 Internal Server Error)

## Шаг третий
В случае успешного ответа оператор открывается доступ к массиву с объектами пользователей по их id в json
